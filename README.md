# 🏧 ATM Simulator - Java

A console-based ATM Simulator developed using **Core Java** and **Object-Oriented Programming (OOP)**. This application simulates basic banking operations such as checking account balance, depositing money, withdrawing cash, and viewing transaction history through a menu-driven interface.

---

## 📖 Description

The ATM Simulator is a beginner-friendly Java project that demonstrates core programming concepts such as classes, objects, methods, loops, conditional statements, encapsulation, and ArrayList. It mimics the functionality of a real ATM in a simplified way.

---

## ✨ Features

- 🏦 Check Account Balance
- 💰 Deposit Money
- 💸 Withdraw Money
- 📜 View Transaction History
- 📋 Menu-Driven Console Interface
- ✅ Input Validation
- 🔄 Continuous User Interaction Until Exit

## ⚙️ How It Works

1. The application starts with a default account balance.
2. Displays a menu of available ATM operations.
3. The user selects an option.
4. Based on the selection, the corresponding banking operation is executed.
5. Every deposit and withdrawal is stored in the transaction history.
6. The application continues running until the user selects **Exit**.
